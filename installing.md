# Running the Pallax App from repo

Follow these steps to clone and run the Pallax App from GitHub:

1. **Environment setup**
   Setup the React Native CLI Environment as instructed [here](https://reactnative.dev/docs/environment-setup)

2. **Clone the repository**

   Open your terminal and navigate to the directory where you want to clone the repository. Use the following command to clone the Pallax App repository:

   \`\`\`bash
   git clone https://github.com/username/pallax-app.git
   \`\`\`

   Replace `username` with the actual GitHub username of the repository owner.

3. **Navigate to the cloned repository**

   Change your current directory to the cloned repository:

   \`\`\`bash
   cd pallax-app
   \`\`\`

4. **Install dependencies**

If the application has any dependencies, you will need to install them. This is usually done with a package manager like npm or yarn. For example, if the project uses npm, you can install the dependencies with:

\`\`\`bash
npm install
\`\`\`

If the project uses yarn, use:

\`\`\`bash
yarn install
\`\`\`

5. **Run the application**

   After installing the dependencies, you can run the application. The command to run the application will depend on how the project is set up. Usually, for npm projects, you can use:

   \`\`\`bash
   npm start
   \`\`\`

   For yarn projects, use:

   \`\`\`bash
   yarn start
   \`\`\`

If the app initial run throws an error, open the android folder on android studio and it will install the necessary native dependencies
